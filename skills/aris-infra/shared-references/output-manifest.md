# Output manifest (Workflow M extract)

A small run needs no duplicate artifact index beyond the pending-patch manifest.
If more than 15 report artifacts are produced, append their timestamp, producing
skill, path and description to `.aris/meta/MANIFEST.md`. Keep this maintenance
index inside the producer's scratch area, not the project-root research manifest.
Never rewrite previous ledger rows. The pending manifest carries advisory evidence
only; the applier generates the fresh binding jury verdict.
