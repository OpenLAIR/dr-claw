## 右侧栏拖动修复与分隔线交互（2026-10-23）

用户追加要求：修复右侧栏无法拖动，并参考 Codex Desktop 的分隔线交互。沿用已确认的视觉方向；本次仅调整侧栏边界和宽度管理，未扩展为右侧内容卡片重排。

原因：原实现用 `aside.parentElement.clientWidth` 计算上限，但桌面父节点是 `display: contents`，其宽度为 0，使拖动上限固定到 360px。另有宽度受 flex 压缩、窗口缩小后未重新约束的问题。

修改：

- 从实际聊天工作区测量可用宽度，使用 ResizeObserver 跟随窗口及左栏宽度变化；显式禁止右栏被 flex 隐式压缩。
- 移除占位的 4px 粗条。静止时保留原 1px 边界，10px 隐形命中区域覆盖边界两侧，悬停显示半透明 2px 中性线，拖动及键盘焦点时加深。
- Pointer Events 与 pointer capture 保持跨区域拖动；动画帧合并更新，拖动结束后保存宽度。取消、失焦、失去捕获和卸载时清理事件与全局光标样式。
- 支持左右方向键、Shift 大步长、Home/End 边界、Enter 或双击恢复默认；中英韩说明与读屏宽度语义齐全。
- 手机继续使用全宽工具页，不显示桌面拖动条。窄桌面按可用空间约束两栏，恢复窗口大小后恢复偏好宽度。

验证：相关 Playwright 回归 28 项通过，其中新增 3 项覆盖浅深色实际鼠标拖动、键盘、存储刷新、上下限、窗口缩放、折叠恢复、双击复位、失焦中断及手机布局。类型检查、生产构建通过；构建仍有既有大 chunk 提示。拖动 hook 源码扫描 0 FAIL / 0 WARN，git diff --check 通过。
